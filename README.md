# 文章跟打器
一個純前端的文章抄寫跟打練習工具。可依書籍分類文章，支援分段、橫書／直書、字體與字級調整、標點自動跳過、閒置暫停計時，並自動保存進度。

## 功能

- **多書籍、多文章**：可建立書籍，將文章分類整理；也可從 JSON 網址載入書籍。
- **分段排版**：支援「空行分段」與「句末分段」，段首自動空兩格。
- **標點自動跳過**：標點、空白、圈號數字、引號等不需輸入，游標自動略過。
- **橫書／直書**：直書為由上而下、由右至左；可橫向捲動。
- **字體與字級**：黑體／宋體／楷體，字級可調，格子隨字級縮放。
- **自動換行**：依視窗寬度（橫書）或高度（直書）自動計算每列字數。
- **輸入判定**：打對變綠、打錯變紅並顯示正解提示；底稿字不可刪除。
- **前後移動與刪字**：方向鍵、Home／End、Backspace／Delete。
- **計時與閒置暫停**：切換分頁或閒置時自動暫停，回來自動續計。
- **進度保存**：以 `localStorage` 自動保存每篇文章的進度與設定。
- **自訂文章**：可輸入標題與內容，並隨時修改。

## 專案結構

```
index.html          主頁面
style.css           樣式
books.json          內建書籍資料（可替換）
favicon.svg         網站圖示
js/
  app.js            入口：組裝模組與事件綁定
  article.js        預設書籍 JSON 路徑、正規化、字體對應
  books.js          書籍／文章新增、查詢、從網址載入
  dialogs.js        自訂文章、新增書籍、新增文章對話框
  grid.js           稿紙渲染、輸入判定、導航
  layout.js         分段、排版、欄數計算、字體字級
  progress.js       進度收集、套用、儲存
  state.js          共享狀態與計時器實例
  storage.js        localStorage 讀寫
  timer.js          計時器（開始／暫停／閒置）
  ui.js             選單、標題、統計、計時標籤
```

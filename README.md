# 文章跟打器
一個純前端的文章抄寫跟打練習工具。可依書籍分類文章，支援分段、橫書／直書、字體與字級調整、標點自動跳過、閒置暫停計時，並自動保存進度。

## 功能

- **多書籍、多文章**：可建立書籍，將文章分類整理；也可從 JSON 網址載入書籍。
- **分段排版**：支援「空行分段」與「句末分段」，段首自動空兩格。
- **標點自動跳過**：標點、空白、圈號數字、引號等不需輸入，游標自動略過。
- **橫書／直書**：直書為由上而下、由右至左；可橫向捲動。
- **字體與字級**：黑體／宋體／楷體，字級可調，格子隨字級縮放。
- **自動換行**：依視窗寬度（橫書）或高度（直書）自動計算每列字數。
- **輸入判定**：打對變綠、打錯變紅並顯示正解提示；底稿字不可刪除。
- **前後移動與刪字**：方向鍵、Home／End、Backspace／Delete。
- **計時與閒置暫停**：切換分頁或閒置時自動暫停，回來自動續計。
- **進度保存**：以 `localStorage` 自動保存每篇文章的進度與設定。
- **自訂文章**：可輸入標題與內容，並隨時修改。

## 專案結構

```
index.html          主頁面
style.css           樣式
books.json          內建書籍資料（可替換）
favicon.svg         網站圖示
js/
  app.js            入口：組裝模組與事件綁定
  article.js        預設書籍 JSON 路徑、正規化、字體對應
  books.js          書籍／文章新增、查詢、從網址載入
  dialogs.js        自訂文章、新增書籍、新增文章對話框
  grid.js           稿紙渲染、輸入判定、導航
  layout.js         分段、排版、欄數計算、字體字級
  progress.js       進度收集、套用、儲存
  state.js          共享狀態與計時器實例
  storage.js        localStorage 讀寫
  timer.js          計時器（開始／暫停／閒置）
  ui.js             選單、標題、統計、計時標籤
```
## 書籍 JSON 格式
```
{
  "bookKey": {
    "title": "書名",
    "articles": {
      "articleKey": {
        "title": "文章標題",
        "label": "選單顯示名稱（可省略）",
        "body": "文章內容，段落之間用空行分隔。"
      }
    }
  }
}
```
如果想新增一本多篇文章的書籍，除了可以逐篇手動新增，還可以直接新增JSON格式的書籍，文章段落以`\n\n`分開，以對應程式中「空行分段」的規則。例如：
```
{
  "lunyu-example": {
    "title": "論語範例",
    "articles": {
      "xueer": {
        "title": "學而篇",
        "label": "學而篇第一",
        "body": "子曰：「學而時習之，不亦說乎？有朋自遠方來，不亦樂乎？人不知而不慍，不亦君子乎？」\n\n有子曰：「其為人也孝弟，而好犯上者，鮮矣；不好犯上，而好作亂者，未之有也。」"
      },
      "weizheng": {
        "title": "為政篇",
        "label": "為政篇第二",
        "body": "子曰：「為政以德，譬如北辰，居其所而眾星共之。」\n\n子曰：「詩三百，一言以蔽之，曰：思無邪。」"
      }
    }
  }
}
```
在「＋ 新增書籍」對話框中選擇「從 JSON 網址載入」，貼上允許 CORS 的 JSON 網址，即可併入書籍清單。載入後的書籍會存入 `localStorage`，下次開啟仍可使用。
